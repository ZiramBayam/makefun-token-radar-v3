Tide Table is a token launch radar built for the make.fun token-radar-01 bounty. It ranks hundreds
of pre-token protocols with a fitted, cross-validated value model and costed farm plans, then renders
an offline dashboard with board, protocol-detail and filtered views.

## Run it

```sh
node main.ts
```
